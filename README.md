# notion-workers

A collection of [Notion Workers](https://developers.notion.com) — small Node/TypeScript
programs hosted by Notion that add Tools, Syncs, or Webhooks to a Notion workspace.

Each subdirectory is a self-contained worker built from the `@notionhq/workers-template`.

> **Note:** The code in this repo was generated with the `/sync` command — a Notion-provided
> agent skill for the Claude Code CLI. See [GENERATED.md](./GENERATED.md) for details.

## Workers

| Worker | What it does |
| --- | --- |
| [`worker-1-github-test/`](./worker-1-github-test) | GitHub integration worker (tool/sync experiments). |
| [`worker-2-google-calendar-test/`](./worker-2-google-calendar-test) | Google Calendar → Notion sync with OAuth. |

## Getting started

Each worker is independent. To set one up:

```bash
cd worker-2-google-calendar-test   # or worker-1-github-test
npm install

# 1. Create your local secrets file from the template, then fill it in.
cp .env.example .env
#    Edit .env — see the variables each worker needs below.

# 2. Connect to your Notion workspace and create your own worker.
#    This generates workers.json (see note below).
ntn login
ntn workers create --name <your-worker-name>
ntn workers env push     # push your .env secrets to the worker
ntn workers deploy
```

Then follow that worker's own `README.md` for the full build, auth, and run details.

## Local config files

Two files are required at runtime but **intentionally not committed** (they're
git-ignored). You create both locally:

### `.env` — secrets

Copy the checked-in `.env.example` to `.env` and fill in real values. Each worker
needs different variables:

| Worker | Variables |
| --- | --- |
| `worker-1-github-test` | `GITHUB_TOKEN`, `GITHUB_REPO` |
| `worker-2-google-calendar-test` | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` |

### `workers.json` — worker identity (do not copy from a teammate)

This file is **generated by the `ntn` CLI**, not written by hand. It maps the
directory to a specific deployed worker via `workspaceId` and `workerId` — values
that are unique to *your* Notion workspace. Running `ntn login` + `ntn workers
create` (as shown above) creates it for you. Don't copy someone else's
`workers.json`, or you'll be pointing at their worker.
